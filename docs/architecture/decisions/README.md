# Architecture Decision Records

This directory records decisions that materially affect the system's
structure.

An ADR should include:

-   **Status:** proposed, accepted, superseded or deprecated.
-   **Context:** the problem or choice being considered.
-   **Decision:** what we chose.
-   **Consequences:** benefits, costs and constraints.
-   **Alternatives:** plausible options considered.
-   **Revisit conditions:** evidence that would justify changing the
    decision.

Accepted decisions are not immutable. If a decision changes, create a
new ADR that supersedes the old one rather than silently rewriting
history.
